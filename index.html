Parallel Circuit — 3 Lamps

Each lamp has its own branch. All branches are connected across the same two points.

💡 Key Concepts (Parallel)

  • Each lamp has the same voltage as the source.
  • The total current is the sum of the branch currents.
  • If one lamp is turned off, the others keep working.
  • Adding more branches decreases the equivalent resistance.

Σ Equations

Itotal = I₁ + I₂ + I₃
1/Req = 1/R₁ + 1/R₂ + 1/R₃
V₁ = V₂ = V₃ = Vsource

Series Circuit — 3 Lamps

All lamps are in a single path. The same current flows through every component.

💡 Key Concepts (Series)

  • The same current flows through all components.
  • The total voltage is the sum of the voltage drops.
  • If one lamp is turned off, all lamps stop working.
  • Adding more components increases the equivalent resistance.

Σ Equations

I₁ = I₂ = I₃ = I
Vtotal = V₁ + V₂ + V₃
Req = R₁ + R₂ + R₃

💡 Key Concepts

  • A dependent source is controlled by another voltage or current somewhere in the circuit. It is drawn with a diamond symbol.
  • This model uses a voltage-controlled current source (VCCS): Iᴅ = gVₓ, where g is the transconductance in siemens.
  • Vₓ is the voltage at node B relative to ground. The dashed cyan line is only a control relation; it is not an electrical wire.
  • KCL must include Iᴅ exactly like any other branch current, but Iᴅ is not found from resistance. It comes from the dependent-source equation.
  • The controlled source can either absorb or deliver power. Dependent does not mean passive.
  • A negative solved branch current means the physical current is opposite to its reference arrow; the animation reverses automatically.

Σ Nodal + Control Equations

(VB − E₁)/R₁ + VB/R₂ + (VB − VC)/R₃ = 0

(VC − VB)/R₃ + VC/R₄ + Iᴅ = 0

Iᴅ = gVₓ

Vₓ = VB

I₁ = (E₁ − VB)/R₁ · I₂ = VB/R₂

I₃ = (VB − VC)/R₃ · I₄ = VC/R₄

Model assumptions: ideal DC sources, ideal wires, linear ohmic resistors and steady state. Positive Iᴅ is defined from C to ground. g is displayed in mS but solved internally in siemens.

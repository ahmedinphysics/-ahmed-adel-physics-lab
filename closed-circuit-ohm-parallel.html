💡 Key Concepts

  • Every closed parallel branch has the same terminal voltage.
  • Total current equals the sum of all active branch currents: Itotal = I₁ + I₂ + …
  • Adding a branch lowers Req and increases the current demanded from the battery.
  • With a real battery, more total current produces a larger internal drop Itotalr, so terminal voltage falls.
  • If r = 0, adding a branch does not change the voltage or brightness of existing lamps.
  • Opening one branch stops only its current; the other closed branches continue working.

Σ Equations

Itotal = ℰ / (Req + r)

1/Req = Σ(1/Ri)

Vterminal = ℰ − Itotalr

Ii = Vterminal/Ri

Pi = Vterminal²/Ri

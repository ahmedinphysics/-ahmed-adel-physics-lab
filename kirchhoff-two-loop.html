💡 Key Concepts

  • This is the first model where Kirchhoff's Current Law and Voltage Law must be satisfied at the same time.
  • Node D is the 0 V reference. The ideal sources fix VA = E₁ and VC = E₂, while VB is determined by all three resistive branches together.
  • Our sign convention is I₁: A → B, I₂: C → B, and I₃: B → D. A negative current is not an error—it means the real current flows opposite to the assumed arrow.
  • At junction B, charge conservation requires I₁ + I₂ = I₃.
  • The left loop requires E₁ − I₁R₁ − I₃R₃ = 0, while the right loop requires E₂ − I₂R₂ − I₃R₃ = 0.
  • If one source is made strong enough, it can drive current backward through the other source branch. Use the “Reverse I₂” preset to see the animation change direction.

Σ Equations

VB = (E₁/R₁ + E₂/R₂) / (1/R₁ + 1/R₂ + 1/R₃)

I₁ = (E₁ − VB) / R₁

I₂ = (E₂ − VB) / R₂

I₃ = VB / R₃

I₁ + I₂ − I₃ = 0

E₁ − I₁R₁ − I₃R₃ = 0

E₂ − I₂R₂ − I₃R₃ = 0

Model assumptions: ideal DC voltage sources, ideal wires, ohmic resistors, steady state, and no internal source resistance. Negative branch current means direction reversal relative to the stated positive direction.

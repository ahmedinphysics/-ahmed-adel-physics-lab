💡 Key Concepts

  • A VCVS is an ideal dependent voltage source whose output voltage is controlled by another circuit voltage.
  • This model enforces VC − VD = μVₓ, with Vₓ = VB. The gain μ is dimensionless.
  • Because the ideal voltage source sits between two non-reference nodes, C and D form a supernode. KCL is written around the whole C-D boundary.
  • The current through an ideal voltage source is not obtained from Ohm's law. It is whatever value is required to satisfy KCL and the source-voltage constraint simultaneously.
  • At μ = 0 the ideal VCVS forces zero volts across itself, but its branch current can still be non-zero. An ideal 0 V voltage source behaves like a current-carrying short constraint.
  • A negative μ reverses the dependent-source polarity relative to the control voltage. The source can either absorb or deliver power.

Σ Nodal + Supernode Equations

(VB − E₁)/R₁ + VB/R₂ + (VB − VC)/R₃ = 0

(VC − VB)/R₃ + VC/R₄ + VD/R₅ = 0

VC − VD = μVₓ

Vₓ = VB

Iᴅ = I₃ − I₄ = I₅

Model assumptions: ideal DC sources, ideal wires, linear ohmic resistors and steady state. Positive Iᴅ is defined from C to D. Positive VCVS voltage is Vᴄ − Vᴅ. μ is dimensionless.
